Muon Optimizer

Adam rescales each weight on its own; Muon treats a weight matrix as a whole and orthogonalizes the update before applying it — a few Newton–Schulz iterations flatten the update's singular values toward one. Every direction gets a comparable step, so the low-energy directions Adam under-serves stop being wasted.

after orthogonalization

Drag the Newton–Schulz step count from 0 to 8 and watch the right-hand spectrum flatten. At 0 it is Adam-shaped; past 5 the gain per step is nearly nothing.

Mixture-of-Experts

A learned router scores every token against N expert FFNs and dispatches it to the top-k, usually two. Only those experts execute, so FLOPs stay near a dense model of a fraction of the size. The cost moves from compute to memory and to balance: an auxiliary loss stops the router collapsing onto a few favourites, and capacity factors decide which tokens get dropped when an expert overflows.

Same primitive, engineer depth: per-expert utilisation over a batch. E3 is near capacity while E2 idles — the imbalance the auxiliary loss is paid to fix.
