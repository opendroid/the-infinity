# theinfinity.ai — an infinitely explorable concept graph for AI/ML.

# The graph is meant to be found. This file blocked everything until the DNS
# cutover (#65, #84) so the pre-launch `web.app` URL would not be indexed and
# leave the history attached to an address we were about to abandon. The domain
# now points at Firebase, so the block is gone.
#
# NOTHING IS DISALLOWED HERE, AND /t/ IS THE INTERESTING CASE. Shared trails are
# reader-created, unbounded, and duplicate the concepts in a different order, so
# they should not be indexed — ADR-0008 says so. They are kept out with
# `X-Robots-Tag: noindex` in firebase.json rather than a `Disallow` line here,
# and the difference is the whole reason this file has a comment:
#
#   robots.txt asks a crawler not to CRAWL. The header tells it not to INDEX.
#   A page linked from elsewhere can be indexed without ever being crawled — so
#   disallowing /t/ would stop the crawler from ever SEEING the noindex, which
#   is the opposite of what it is for.
#
# /search and /request are crawlable and simply absent from the sitemap: one is
# a tool and the other is a form, and neither is worth a rule.
